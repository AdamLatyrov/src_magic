# Проверки комплекта

Проверки выполнены 9 ноября 2026 года на Windows с Python 3.12.10.

## Что прошло

- Все Python-файлы в `src` скомпилированы штатным `compile` без ошибок.
- JSON ноутбука читается, все его кодовые ячейки разбираются как Python.
- Первые пять исполняемых ячеек ноутбука выполнены без сетевых запросов. Они загрузили настройки и демонстрационный каталог, создали провайдера с фиктивным адресом и подготовили три кадра и запрос.
- Конструктор `AnalysisPipeline` собрал граф на демонстрационном каталоге.
- Поля `PipelineRequest`, `PipelineRunResult` и `PipelineStateSnapshot` совпали с версиями в переданном архиве `cg_pro_analysis_worker_src_reviewed.zip`.
- Тесты pipeline: 27 прошли. Для асинхронных тестов использован одноразовый локальный pytest-hook, потому что в доступном окружении нет `pytest-asyncio`. Файлы проекта для этого не менялись.
- Русские README, руководство, контракт и ADR проверены линтером `humanizer-ru` без замечаний. В тексте ноутбука линтер отметил только ровный темп предложений; жёстких ошибок нет, замечание проверено и не мешает пониманию шагов.
- Поиск по передаваемым исходникам не нашёл ссылок на удалённый экспериментальный провайдер, его переменные окружения или трассировку.

## Ограничения результата

- В обычном окружении проекта pytest отсутствует. Тесты были запущены системным Python с временным hook для корутин.
- В тестовом выводе остаются предупреждение Pydantic об устаревшем синтаксисе настроек и предупреждения о незарегистрированной метке `asyncio`. Все корутины при этом были выполнены hook-ом.
- Полный ноутбук не запускался, потому что он отправляет запросы к модели и требует действующего разрешённого доступа.
- Не проверялись сетевой адрес, авторизация, сертификат, модель, обработка изображений и полный прогон на GigaChat.
- Демонстрационные кадры и каталог не заменяют GoldSet. Качество модели на них не измерялось.
- Интеграционный HTTP-обработчик, долговременное хранение и восстановление после перезапуска здесь не проверялись.
