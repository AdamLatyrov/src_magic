# Изменения интерфейса и комплекта

## 2026-11-09

- Добавлен расширенный снимок состояния с ревизией, временем обновления, статусом анализа, причинами деградации, сбойными блоками и использованными fallback-ответами.
- Добавлен `get_state_json(run_id)`, который возвращает готовый JSON-совместимый снимок для HTTP-обработчика интеграции.
- Поля `PipelineRequest`, `PipelineRunResult` и `PipelineRunResult.state` сохранены совместимыми с переданным архивом.
- Ноутбук показывает запуск через штатный провайдер GigaChat и печатает итоговый список находок.
- Добавлены списки runtime- и тестовых зависимостей pipeline; виртуальная среда в комплект не входит.

Снимки существуют только в памяти текущего процесса. Долговременное хранение и восстановление задачи остаются в интеграции.
