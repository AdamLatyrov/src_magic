# CG Pro Analysis Worker

Комплект состоит из двух частей. `pipeline` анализирует последовательность экранов. `integration` отвечает за продукт, задания, данные и их хранение. Общий вход из Python находится в `main.py`, пример вызова открыт в `main_notebook.ipynb`.

## С чего начать

1. Откройте `pipeline/README.md`, чтобы понять назначение пакета.
2. Прочитайте `pipeline/documentation/contract.md` перед подключением.
3. Запустите ноутбук в Python-окружении проекта и укажите разрешённые настройки GigaChat.
4. Передайте `pipeline.get_state_json(run_id)` из HTTP-обработчика интеграции, если клиент запрашивает прогресс.

Для `pipeline` и ноутбука версии Python-пакетов перечислены в `pipeline/requirements.txt`. Для тестов добавьте пакеты из `pipeline/requirements-test.txt`. Устанавливайте их из разрешённого источника. Зависимости развёртывания сервиса из `integration` задаются отдельно.

Ноутбук использует демонстрационные кадры и демонстрационную выгрузку критериального каталога. Они нужны для проверки запуска и не являются GoldSet или подтверждением качества модели.

## Где лежат материалы

- `main.py` - публичный фасад и схемы его зависимостей.
- `main_notebook.ipynb` - пошаговый пример подготовки и запуска одного прогона.
- `pipeline/` - граф анализа, провайдер GigaChat, схемы, тесты и документация.
- `integration/` - отдельный пакет интеграции с её собственными настройками и хранением.

После перезапуска процесса снимки pipeline исчезают. Интеграция заранее записывает нужные состояния и результат в своё хранилище.
