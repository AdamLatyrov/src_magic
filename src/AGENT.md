# Правила работы с комплектом

- Публичный интерфейс интеграции с анализом определён в `main.py`.
- Код анализа, схемы, тесты и документация находятся в `pipeline/`.
- Код в `integration/` принадлежит отдельной зоне ответственности. Не менять его при задачах только по pipeline.
- Pipeline не импортирует интеграцию и не отвечает за продуктовый выбор, очередь, БД, S3 или долговременное хранение.
- Сохранять форму `PipelineRequest` и `PipelineRunResult`, если отдельная задача не требует изменения контракта.
- Прогресс публиковать только через публичные снимки. Не отправлять в них изображения, ключи или необработанные сообщения модели.
- Проверять Python-компиляцию, тесты pipeline, JSON ноутбука и отсутствие экспериментального кода, который удалён из комплекта.
- Не заявлять о живой совместимости модели или качестве анализа без соответствующего прогона.
